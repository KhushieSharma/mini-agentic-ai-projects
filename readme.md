This repo consists of a few mini projects and basic intro regarding langgraph and langchain. Basically how langgraph can be used in multiple cases and workflows. 
So the major project here is the chat bot with memory that you can talk to, also streaming responses just like chatgpt and it also shows u your message history.
Another one here is an essay evaluator, it consists of multiple agents that evaluate and critic your essay.
There there are basic files that help understand langgraph better.
